# Security Policy

## Supported Versions

Security updates are provided for the latest version of the project.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue.

Report it privately to the maintainer through GitHub:

https://github.com/Vitthal434/ATS-Resume-Evaluator

Please include:

- A clear description of the issue.
- Steps to reproduce it.
- Any potential impact.

The maintainer will review the report and respond as soon as possible.
