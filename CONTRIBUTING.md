# Contributing

Thank you for your interest in contributing to ATS Resume Evaluator.

## How to Contribute

1. Fork the repository.
2. Create a feature branch.
3. Make one focused change per pull request.
4. Keep existing functionality working.
5. Add or update documentation when needed.

## Development Guidelines

- Keep code readable, modular, and consistent with the existing style.
- Follow Python and Flask best practices.
- Avoid unrelated formatting or refactoring changes.
- Test your changes before opening a pull request.

## Pull Requests

Include a clear summary of what changed and why. Reference related issues when applicable.
